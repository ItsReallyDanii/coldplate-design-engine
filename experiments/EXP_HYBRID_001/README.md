# EXP_HYBRID_001

Serpentine + diamond TPMS hard-split hybrid.

## Construction
hybrid[z,y,x<N] = serpentine; hybrid[z,y,x>=N] = diamond
- hybrid_25: N=10 of 40
- hybrid_50: N=20 of 40

## Run
```bash
cd coldplate-design-engine
python experiments/EXP_HYBRID_001/run_exp_hybrid_001.py
```
